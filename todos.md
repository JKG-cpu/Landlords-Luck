# Game breakdown

| Todos, parts / features of the whole game

## Game Manager (Autoload)

This should control basically the whole game
  - Money
  - Reputation
  - Saving / Loading Data
  - Etc

## Property Manager

This holds everything about
  - Property Ownership
  - Buildings
  - Upgrades
  - Selling

## Tenant Manager

Manages properties
  - Rent
  - Tenants
  - Evictions
  - Reputation Effects

## Auction Manager

This manages 
- Property Listings
- Auctions
- Bids

## Time Manager

Holds data about 
  - Days, Weeks, Months...
  - Rent collection (sends signals based off of the time)
  - Refreshes (Shop, auctions, etc)
